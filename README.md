# Лабораторная работа №1. Трубопроводный транспорт

Консольная программа на C++ для учёта двух объектов газотранспортной системы: **трубы** и **компрессорной станции (КС)**. Объекты можно добавлять, просматривать, редактировать, сохранять в текстовый файл и загружать обратно.

## Возможности

- добавление трубы и КС с проверкой вводимых значений;
- просмотр всех добавленных объектов;
- редактирование трубы (признак «в ремонте»);
- редактирование КС (запуск и остановка цеха);
- сохранение в файл: можно сохранить и трубу, и КС, или только один из объектов;
- загрузка из файла, в котором есть труба, КС или оба объекта.

## Меню

```
1. Добавить трубу
2. Добавить КС
3. Просмотр всех объектов
4. Редактировать трубу (признак 'в ремонте')
5. Редактировать КС (запуск/останов цеха)
6. Сохранить в файл
7. Загрузить из файла
0. Выход
```

В программе хранится одна труба и одна КС. Повторное добавление заменяет объект.

## Данные объектов

**Труба**

| Поле | Описание | Допустимые значения |
|---|---|---|
| `mark` | километровая отметка (название участка) | непустая строка |
| `lengthKm` | длина, км | от 0.001 до 100000 |
| `diameterMm` | диаметр, мм | от 1 до 100000 |
| `underRepair` | признак «в ремонте» | да / нет |

**Компрессорная станция**

| Поле | Описание | Допустимые значения |
|---|---|---|
| `name` | название | непустая строка |
| `totalShops` | количество цехов | от 1 до 1000 |
| `shopsInOperation` | цехов в работе | от 0 до `totalShops` |
| `stationClass` | класс станции | от 1 до 10 |

При неверном вводе программа сообщает об ошибке и просит повторить. Запустить цех можно, пока не все цехи в работе, остановить можно, пока в работе есть хотя бы один.

## Формат файла

Файл текстовый. Каждый объект записывается в своём разделе строками вида `ключ=значение`. Если объекта нет, его раздел не пишется.

```
[PIPE]
mark=Участок-1
lengthKm=12.500000
diameterMm=720
underRepair=0
[STATION]
name=КС-1
totalShops=5
shopsInOperation=3
stationClass=2
```

Правила:

- раздел `[PIPE]`, если он есть, идёт первым, раздел `[STATION]` следует за ним;
- допустимы файлы только с `[PIPE]`, только с `[STATION]` или с обоими разделами;
- `underRepair` записывается как `1` (в ремонте) или `0` (не в ремонте);
- загрузка заменяет текущее состояние целиком: если в файле нет КС, то после загрузки КС в программе тоже нет;
- если файл повреждён (пустой, неизвестный заголовок, оборван, неверный формат числа), программа выводит причину и оставляет текущие данные без изменений.

Имя файла можно выбрать любое. Расширение `.txt` в `.gitignore` исключено из репозитория, поэтому для файлов с данными удобнее брать, например, `.dat`.

## Пример работы

```
===== МЕНЮ =====
...
Выберите пункт: 1
--- Ввод данных трубы ---
Километровая отметка (название участка): Участок-1
Длина трубы, км (> 0): 12.5
Диаметр трубы, мм (> 0): 720
Труба в ремонте? (y/n): n
Труба добавлена.

Выберите пункт: 6
Имя файла для сохранения: pipe.dat
Данные успешно сохранены в файл 'pipe.dat'.
```

В файл `pipe.dat` попадёт только раздел `[PIPE]`, потому что КС не добавлялась.
